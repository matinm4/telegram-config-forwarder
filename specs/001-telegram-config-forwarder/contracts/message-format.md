# قرارداد: قالب پیام (MessageFormat)

> این فایل به **زبان فارسی** نوشته شده است. نام‌ها و امضاها انگلیسی باقی می‌مانند.

## هدف

ساخت پیام نهایی مرتب و قابل تنظیم برای هر مقصد (FR-020/FR-021).

## الگوی پیش‌فرض

```text
🔗 کانفیگ جدید ({protocol}) — {location_display}

<code>{config_raw}</code>

📍 موقعیت: {location_display}
🧪 تست: {test_status_fa} {latency_suffix}
📢 {destination_username}
```

- `{test_status_fa}`: موفق / ناموفق / timeout / انجام‌نشده.
- `{latency_suffix}`: فقط وقتی `latency_ms` موجود است، مثل `(‏۱۲۴ میلی‌ثانیه)`.
- `{destination_username}`: فقط وقتی افزودن نام کاربری فعال است.

## قرارداد

- ورودی: کانفیگ + موقعیت + نتیجه تست + تنظیمات قالب همان مقصد.
- خروجی: رشته `body` آماده ارسال؛ طول در سقف تلگرام (در صورت تجاوز، کانفیگ بدون تغییر و فراداده خلاصه می‌شود).
- هیچ secret یا رشته اتصال حساس جدا از خود کانفیگ در پیام نیست.
- قالب هر مقصد مستقل است و تغییر آن بدون تغییر کد اعمال می‌شود.
