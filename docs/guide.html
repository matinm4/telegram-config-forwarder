🚀 راهنمای ساده سامانه کانفیگ تلگرام

فقط ۵ قدم — همه کارها با مرورگر، بدون دستور

قدم ۱ — پروژه را به گیت‌هاب بفرست (فقط یک‌بار)

این قدم را هر جا اینترنت آزاد داری انجام بده. بعد از آن دیگر لازم نیست.

در سایت github.com یک مخزن عمومی جدید بساز، بعد در پوشه پروژه:
git remote add origin <YOUR-REPO-URL>

git push -u origin main

قدم ۲ — توکن ربات را وارد کن (فقط یک‌بار)

۱. از @BotFather در تلگرام توکن بگیر
۲. ربات را در کانال‌های مقصد ادمین کن
۳. در صفحه مخزن برو به:
Settings → Secrets → Actions → New secret
اسم: BOT_TOKEN — مقدار: توکن ربات

قدم ۳ — کانال‌هایت را معرفی کن (تو سایت گیت‌هاب!)

۱. در صفحه مخزن روی فایل config.yaml کلیک کن
۲. دکمه ✏️ (مداد / Edit) بالای فایل را بزن
۳. نام کانال منبع و مقصد خودت را جایگزین مقادیر نمونه کن:
username: "example_channel" ← کانال منبع تو
chat: "@my_channel" ← کانال مقصد تو
۴. دکمه سبز Commit changes را بزن — تمام!
💡 از این به بعد هر تغییری (منبع جدید، مقصد جدید، خاموش/روشن کردن تست) را همین‌جا با دکمه مداد انجام بده. از اجرای بعدی خودکار اعمال می‌شود.

قدم ۴ — اولین اجرا را دستی بزن

در صفحه مخزن برو به تب Actions ← از لیست سمت چپ forwarder ← دکمه Run workflow ← Run workflow

بعد از ۲-۳ دقیقه نتیجه را در کانال مقصدت ببین. از اینجا به بعد سیستم خودش هر ۳ ساعت اجرا می‌شود.

قدم ۵ — نتیجه را ببین

کجاچه می‌بینی
کانال مقصدکانفیگ‌های تازه با موقعیت و وضعیت تست
کانال قرنطینهکانفیگ‌هایی که تستشان ناموفق بود (جدا از بقیه)
تب Actionsخلاصه هر اجرا: چند پست، چند ارسال، چند خطا

🛠️ اگر چیزی درست کار نکرد

مشکلراه‌حل در یک جمله
هیچی ارسال نشدBOT_TOKEN را در Secrets چک کن و ربات را ادمین کن
