⬇️ گام ۲ — نصب

⚙️ گام ۳ — ساخت پیکربندی

cp config.example.yaml config.yaml

فایل config.yaml را ویرایش کنید. مهم‌ترین گزینه‌ها:

گزینهاثر
sources[].usernameکانال منبع (بدون @ هم قبول است)
destinations[].chatکانال مقصد؛ یکی را quarantine: true کنید
distribution.strategyپیش‌فرض round_robin
testing.enabled / location.enabledبرای شروع می‌توانید false بگذارید
schedule.interval_hoursباید با cron گردش کار یکی باشد (پیش‌فرض ۳)

شرح کامل همه گزینه‌ها: docs/CONFIGURATION.fa.md

🔐 گام ۴ — تنظیم اسرار (خیلی مهم)

⚠️ توکن و نشست را هرگز داخل فایل، عکس یا پیام فورواردی نگذارید. فقط متغیر محیطی:
# ویندوز (موقت، فقط همان ترمینال):
set BOT_TOKEN=123456:ABC...
# لینوکس/مک:
export BOT_TOKEN=123456:ABC...
متغیرالزامی؟
BOT_TOKENبله
API_ID / API_HASH / SESSION_STRINGفقط مسیر دوم
MAXMIND_LICENSE_KEYفقط اگر موقعیت فعال است

🧪 گام ۵ — اجرای آزمایشی محلی

pytest tests/ -q
python -m src.main --config config.yaml --once

خروجی موفق شبیه این است:

دریافت: 4 | استخراج: 4 | ارسال موفق: 4 | ناموفق: 0
💡 اجرای دوم بدون پست جدید باید صفر ارسال داشته باشد (تست Idempotency).

☁️ گام ۶ — پوش به گیت‌هاب

git init
git add .
git commit -m "feat: telegram config forwarder (spec-kit converged)"
git branch -M main
git remote add origin <YOUR-REPO-URL>
git push -u origin main
⚠️ قبل از push مطمئن شوید فایل config.yaml واقعی (حاوی شناسه‌های شخصی) یا هیچ secretای کامیت نمی‌شود. state/state.json مشکلی ندارد.

⏰ گام ۷ — فعال‌سازی اجرای خودکار

۱

۲
تب Actions → فعال‌سازی workflowها → اجرای دستی forwarder با Run workflow.
۳
زمان‌بندی خودکار هر ۳ ساعت (0 */3 * * *) از همان اول فعال است؛ کاری لازم نیست.
